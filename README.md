# JS-repo

A complete code repository for the JavaScript Series, covering topics from basic syntax to advanced object-oriented programming, DOM manipulation, and asynchronous JavaScript, with hands-on code examples for each concept.

## Contents

| Folder | Topics Covered |
|---|---|
| 01_Basics | Variables, data types, type conversion, comparisons |
| 02_Basics | Strings, numbers, math operations, dates |
| 03_Basics | Arrays and array methods, objects |
| 04_control_flow | Functions, scope, arrow functions, IIFEs |
| 05_iterations | If-else, switch statements, truthy/falsy values |
| 06_dom | Loops: for, while, for-of, for-in |
| 07_projects | DOM manipulation and element selection |
| 08_events | Mini practice projects |
| 09_advance_one | Event handling and listeners |
| 10_classes_and_oop | Promises, async/await, API requests |
| 11_fun_with_js | Classes, inheritance, prototypes, getters/setters, this binding, closures |

## Usage

Clone the repository:

```
git clone https://github.com/asifn0093/JS-repo.git
```

Run JavaScript files with Node.js:

```
node filename.js
```

HTML files can be opened directly in a browser to view DOM and event-handling examples.
